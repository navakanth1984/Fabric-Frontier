# /compact-memory

Summarize today's session log and append key learnings to long-term memory.

## Steps

1. Read `memory_os/session_memory/session_<today>.md`.
2. Extract: decisions made, files changed, blockers hit, things learned.
3. Append a dated summary block to `memory_os/long_term_knowledge/knowledge.md`.
4. Truncate today's session log to just the summary (keep it lean).
5. Report what was saved.

## Format for long-term entry

```markdown
### <YYYY-MM-DD>
- **Decisions:** ...
- **Files changed:** ...
- **Learned:** ...
- **Blockers:** ...
```
